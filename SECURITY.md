# Security policy

## Scope

Security work currently covers the inspector on main: untrusted PE parsing, bounded resource use, path/privacy handling and development supply-chain changes. There is no supported playable release. Report the precise commit or tool version and the affected platform.

## Reporting

For an exploitable vulnerability, use **Security → Report a vulnerability** when that private reporting control is available. Otherwise, open an issue titled **Private security contact requested**, without exploit details, and request a private channel from `@ranzevor`. Do not attach game executables, saves, credentials, personal paths or a public proof of exploitation.

A private report should describe the affected revision, impact, reproduction using a minimal original input, and a proposed fix when available. Ordinary non-sensitive defects belong in the bug-report form. Publication of an advisory or patched release is a separate maintainer decision.
