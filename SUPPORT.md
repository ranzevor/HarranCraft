# Support

Read the [inspector guide](docs/inspector.md) and [compatibility matrix](docs/compatibility.md) before opening an issue. Use the defect form for a reproducible failure and the feature form for a concrete missing behavior. English and Simplified Chinese are accepted.

Include the HarranCraft commit/tool version, operating system, Python version, command options, exit code and a sanitized report. Reports identify inputs by position; game files and personal paths are unnecessary. A failed file inspection does not require installing or starting a game.

HarranCraft does not yet provide a playable mod or game installer. Requests about the inspector and development work can be evaluated independently of future real-game tests. Sensitive findings follow [SECURITY.md](SECURITY.md).

## 简体中文

提交 Issue 前，请查看[核查工具指南](docs/zh-CN/inspector.md)和[兼容矩阵](docs/zh-CN/compatibility.md)。可复现故障使用缺陷表单，具体能力需求使用功能表单，可使用英文或简体中文。

提供 HarranCraft 提交／工具版本、系统、Python 版本、命令选项、退出码及去除敏感信息的报告。报告按输入顺序编号，不需要游戏文件或个人路径；文件核查失败不要求安装或启动游戏。

当前尚未提供可玩模组或游戏安装器；核查工具和开发问题可以独立处理。敏感问题按[安全政策](SECURITY.md)报告。
